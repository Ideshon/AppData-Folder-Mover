# Folder Mover v18

Программа переносит выбранную локальную папку в новое место и создаёт на старом пути NTFS junction-ссылку.

Верхнее описание окна сохранено. Подписи под строками выбора сделаны универсальными.

## Главное исправление v18

Обычный режим `Перенести` снова работает как перенос папки **в папку назначения**.

Пример:

```text
Что переносим:
C:\Users\Ideshon\Documents\Electronic Arts

Куда переносим:
G:\C-Link\Documents
```

Итоговая папка будет:

```text
G:\C-Link\Documents\Electronic Arts
```

Ссылка будет создана так:

```text
C:\Users\Ideshon\Documents\Electronic Arts -> G:\C-Link\Documents\Electronic Arts
```

Если в поле `Куда переносим` уже указан путь, который заканчивается именем исходной папки, повторно имя не добавляется.

Пример:

```text
Что переносим:
C:\Users\Ideshon\Documents\Electronic Arts

Куда переносим:
G:\C-Link\Documents\Electronic Arts
```

Итоговый путь останется:

```text
G:\C-Link\Documents\Electronic Arts
```

## Исправление уже ошибочно перенесённой папки

Если ранее получилось так:

```text
C:\Users\Ideshon\Documents\Electronic Arts -> G:\C-Link\Documents
```

а нужно так:

```text
C:\Users\Ideshon\Documents\Electronic Arts -> G:\C-Link\Documents\Electronic Arts
```

используйте обычную кнопку `Перенести`:

```text
Что переносим:
C:\Users\Ideshon\Documents\Electronic Arts

Куда переносим:
G:\C-Link\Documents
```

или явно:

```text
Куда переносим:
G:\C-Link\Documents\Electronic Arts
```

Программа увидит, что исходная папка уже является junction-ссылкой, и вместо обычного копирования выполнит исправление:

1. создаст `G:\C-Link\Documents\Electronic Arts`;
2. перенесёт внутрь неё содержимое из `G:\C-Link\Documents`;
3. пересоздаст junction-ссылку на новый путь.

## Режимы

- `Перенести` — обычный перенос папки с созданием junction.
- `Переезд базы` — перенос уже вынесенной базы с переназначением найденных ссылок.
- `Слить базы` — объединение двух похожих баз, например `G:\Appdata\Appdata -> G:\Appdata`.
- `Проверить` — проверка плана и занятости папки одной кнопкой.

## Важно

- Для обычного переноса поле `Куда переносим` теперь считается папкой назначения, а не обязательно точным итоговым путём.
- Для `Переезд базы` и `Слить базы` путь используется как итоговая база/итоговая папка режима.
- Не удаляйте junction вручную через `Remove-Item -Recurse`; для удаления ссылки безопаснее использовать `rmdir "путь_ссылки"`.
- Целевой диск должен быть NTFS.
